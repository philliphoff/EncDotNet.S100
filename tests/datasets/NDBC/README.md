# NDBC fixtures

Fixtures for `EncDotNet.S100.DynamicSources.Ndbc.Tests`: two `realtime2`
standard meteorological files and a station table.

| File | Station | Size | Origin |
| --- | --- | --- | --- |
| `44013.txt` | 44013, moored buoy, BOSTON 16 NM East of Boston, MA | 14,012 bytes, 144 rows (24 h) | Hand-written |
| `BUZM3.txt` | BUZM3, C-MAN station, Buzzards Bay, MA | 14,012 bytes, 144 rows (24 h) | Hand-written |
| `activestations.xml` | 44013, BUZM3, 44020, 44401 (DART, no met data), 46026, and one malformed entry | 1.6 KB | Hand-written excerpt |

**These fixtures are synthetic.** NOAA's hosts (`www.ndbc.noaa.gov`) were
blocked from the environment that built #1070, so no file could be captured.
They follow NDBC's documented format exactly:

- `realtime2/{station}.txt`: two header lines,
  `#YY  MM DD hh mm WDIR WSPD GST  WVHT   DPD   APD MWD   PRES  ATMP  WTMP  DEWP  VIS PTDY  TIDE`
  and the units line, then 10-minute rows, newest first, with `MM` for a
  missing value. The column widths match NDBC's files. The buoy reports
  waves once an hour (the `:50` rows), the pressure tendency on the hour,
  and drops one wind report (13:40). The C-MAN station has no wave or water
  temperature sensors, so those columns are `MM` throughout.
- `activestations.xml`: `<stations>` of `<station id lat lon elev name owner
  pgm type met currents waterquality dart/>`, as NDBC publishes it. Station
  positions and names are the real stations'; `buzm3` is lower case, as the
  parser must upper-case ids to match the `realtime2` file names. 44020 has
  no fixture file, so the source tests see a 404 for it.

The values are generated by a small script (smooth daily curves for wind,
pressure and temperature) and are not observations. NOAA data is US
government work and public domain, so real captures can replace these files
directly: keep the names, and update the value assertions in
`NdbcRealtimeParserTests` (the newest row of each file) and the station
count in `NdbcStationTableTests`. The source tests take the clock from each
file's newest row, so they don't depend on the dates.

Sources a real capture would come from:

- `https://www.ndbc.noaa.gov/data/realtime2/44013.txt`
- `https://www.ndbc.noaa.gov/data/realtime2/BUZM3.txt`
- `https://www.ndbc.noaa.gov/activestations.xml`
- Format: NDBC, "Measurement Descriptions and Units",
  `https://www.ndbc.noaa.gov/faq/measdes.shtml`.
