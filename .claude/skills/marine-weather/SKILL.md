## Architecture in this repo
- **Grid model** (`Datasets.Weather`, no GRIB/NetCDF code): a reader builds
  `WeatherNativeGrid` (as stored) + `WeatherParameter`s with lazy
  `WeatherTimeStep` decoders → `WeatherGridSet`. `WeatherGridLayout`
  normalises to south-west origin, rows north, columns east, lon −180..180;
  missing → `NaN`. Canonical ids and stored units live in `WeatherParameters`
  (lookup by GRIB2 code or CF `standard_name`); unknown params are kept for
  `info` but not drawn.
- **Coverage**: `WeatherCoverageSource.CreateForGroups` → one `ICoverageSource`
  per parameter group/level; derives `wind.speed`/`wind.from_direction` and
  `current.speed`/`current.to_direction` from U/V; synthesises a combined
  `spray` source (`FreezingSpray.Predictor`). Lazy decode, LRU of 2 steps.
- **Styles**: 15 `WeatherCoverageStyle` subclasses (code-defined, portrayal
  toolkit, `WeatherPalette`, SVGs in `Symbols/` generated by
  `tools/GenerateWeatherSymbols`); `WeatherPortrayal.BuildAsync` builds the
  sub-layers. `IsDrawnWith` reads `EcdisDisplaySettings.LayerVisibility`.
- **GRIB2** (`Datasets.Grib`): `GribFile` indexes; `GribWeatherDataset`
  (`Open`, `OpenFolder`) groups fields, picks levels/runs, records
  `IgnoredFields`. Managed JPEG 2000 under `Internal/Jpeg2000`.
- **NetCDF** (`Datasets.NetCdf`): `NetCdfFile` (3 and 4) → `CfWeatherReader`
  → `NetCdfWeatherDataset`.
- **Vector weather**: `CapReader` → `CapWarningSet` (zones from
  `MarineZoneLayer.Default`, bundled NWS GeoJSON) → `CapStyle`;
  `NhcAdvisoryReader` → `TropicalCycloneAdvisory` (`StormAt`) →
  `TropicalCycloneStyle` (lives in `Datasets.Weather`);
  `CodedSurfaceBulletinReader` → `SurfaceAnalysis` → `SurfaceAnalysisStyle`.
- **S-412**: `S412Dataset`/`S412DatasetReader` → typed
  `S412MarineWeatherWarnings` (projection only; portrayal doesn't use it);
  `S412PortrayalCatalogue` serves a corrected wave-height rule at load time.
- **NDBC**: `NdbcObservationSource` is an `IDynamicFeatureSource` (polls
  `realtime2` with HTTP `Range`), `NdbcStationPortrayal` reuses
  `WindBarbSymbols`.

## Review checklist
1. Readers convert to the **stored unit** of the parameter table (m/s, m,
   Pa, K, degrees true); quantities cross the public API as `Speed`/`Length`/
   `Angle`, bulk grids stay `float`. Styles define bands in kn/°C/hPa and
   convert limits — never copy the grid into display units.
2. New parameter: add a row in `WeatherParameters` with GRIB code(s) in
   preference order + CF names; update the README tables and `docs/weather.md`.
3. Style change (symbol, colour, band) → bump `StyleVersion`; keep palette
   clear of S-101 depth/danger/mariner hues and S-104 teal; Night < 0.2 luminance.
4. Layer planes/priorities match README: fills `OnDemandSurface` 0, barbs/
   arrows `DynamicArrows` 20, isolines 90, fronts 92, TC track 95, NDBC 100.
5. Unsupported input fails with a message naming the template/grid/filter
   (`UnsupportedGribException`, `UnsupportedWeatherGridException`,
   `CfConventionsException`, `NetCdfFormatException`), or is listed in
   `IgnoredFields`/`IgnoredVariables` — never silently dropped.
6. Warning time uses `WarningValidity` (`src/EncDotNet.S100.Core/DatasetPipelines/WarningValidity.cs`),
   shared by S-124, CAP and S-412 so all start/end alike.
7. Output carries the "Not for navigation" labelling (Datasets panel, pick,
   `s100 info`/`identify`).

## Known pitfalls
- **Directions:** wind and waves are "from", currents are "to" (as S-111),
  clockwise from true north. `wind.from_direction = atan2(−u, −v)`,
  `current.to_direction = atan2(u, v)`. Wave arrow adds 180°; barbs mirror
  south of the equator (`WXBARBS*`).
- **GRIB support limits:** grid template 3.0 only; product 4.0 and 4.8 only
  (no ensembles 4.1/4.11); data 5.0, 5.2, 5.3, 5.40, 5.41. CCSDS 5.42 (all
  ECMWF Open Data) and GRIB1 are unsupported (`weather-sources.md` §10.6).
- **APCP:** GFS writes overlapping buckets; each step keeps the period since
  the previous step (differencing), with `Interval` on each step. Template
  4.8 `ValidTime` is the interval **end**.
- **Grids:** regional grids across the antimeridian are rejected (open
  question §10.3); curvilinear, Lambert, polar, Gaussian also rejected.
- **CF:** time only in s/min/h/days since, standard/gregorian calendars;
  NetCDF-4 groups, CDF-5, multi-level variables unsupported.
- **Time is UTC** (GRIB, CF, S-412 `FixedDateRange`, TC `ValidTime`). Except:
  NHC `IssueTime` keeps NHC's local offset; WPC short valid times are dated
  from the bulletin header (or file mtime when absent).
- **CAP:** `expires` can precede the hazard; end is the later of `expires`
  and `ends`/`eventEndingTime`. Unmatched UGC zones go to
  `UnmatchedZoneCodes`, not dropped.
- **S-412 draft quirks:** upstream sample has off-schema dates (`20250101`,
  `0600`) and a cancellation before its start; enumerations keep the `code`
  attribute as value. Don't edit bundled `content/S412` files.
- **Licensing of samples:** NOAA/NWS/NHC/NDBC data is public domain and
  committed; ECMWF (CC BY 4.0) and Copernicus Marine (account, attribution)
  bytes must not be committed — generate them via `tests/_shared` helpers.
  GRIB fixtures rebuild with `tools/grib-fixtures/*.py`.
- `docs/weather.md` "What isn't supported" still says S-412 isn't
  published; the S-412 reader exists (draft) — don't trust that line.
