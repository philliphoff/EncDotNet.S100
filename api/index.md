# API reference

Generated reference for every public type in the EncDotNet.S100 NuGet
packages. Pick a namespace from the table of contents, or search.

New to the libraries? Start with [Getting started](../docs/getting-started.md),
then [Top APIs](../docs/top-apis.md) for the most useful entry point in each
package. Each package's README, under [Packages](../src/EncDotNet.S100/README.md), explains what
it is for and how to use it.

The `EncDotNet.S100` package is the batteries-included facade:
`S100Dataset.Open` opens a dataset and `PngS100DatasetRenderer` renders it.
Drop to the per-package APIs listed here when you need custom catalogues,
asset sources, or low-level control.
